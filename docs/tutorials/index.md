# Tutorials

## Query Expansion Revisited: From Classical Retrieval to Agentic Search

Presented at the 35th ACM International Conference on Information and Knowledge Management (CIKM 2026), November 7–11, 2026.

Amin Bigdeli, Radin Hamidi Rad, Hai Son Le, Yibin Lei, Andrew Yates, Negar Arabzadeh, Charles Clarke, Ebrahim Bagheri

The tutorial covers traditional, neural and LLM-based query expansion; query expansion across search paradigms, including retrieval-augmented generation, conversational search and agentic search; and system design and best practices.
